机票兑换成本计算器 · 本地版

一、电脑直接使用（无需安装依赖）
双击「机票兑换成本计算器.html」，或用浏览器打开 index.html。
单文件 HTML 已包含样式与计算代码，复制到另一台 Windows / macOS 电脑即可使用。
首次显示明确标注的示例数据，请改成自己的数值。
核心计算可离线使用；在线自动获取汇率。第一次离线时，请填写实际汇率。

二、手机与电脑一起使用
电脑需安装 Python 3，手机与电脑连接同一 Wi-Fi。
macOS：双击 start-mac.command；或终端运行 python3 server.py --lan --open
Windows：双击 start-windows.bat；或终端运行 py -3 server.py --lan --open
电脑地址：http://localhost:8765
手机地址：使用终端打印的局域网地址。
电脑需要保持运行。停止服务：终端 Ctrl+C。
若端口已占用，可运行 python3 server.py --lan --port 8766（Windows 使用 py -3）。
手机无法访问时，检查是否同一 Wi-Fi，以及防火墙是否允许 Python 的局域网连接。
只在本机使用时，可运行 python3 server.py（默认仅监听 127.0.0.1）。
服务只提供计算器的公开网页文件，不提供目录列表。
手机通过电脑访问时无需互联网即可计算，但仍需能连接电脑；当前不提供手机独立离线安装。

三、计算口径
点数、兑换税费、含税现金票价均填写「全部乘客、完整行程」的总数。
自动查询支持成人、儿童与婴儿分类；人数不再次乘入计算。往返机票应填写往返总价。
税费与票价分别支持 USD / CNY，先统一换成美元计算，结果同时显示人民币与美元。
CPP 始终是美分／点；人民币／千点 = CPP × 10 × 人民币／美元汇率。
两边都可修改，汇率变化时保留最后编辑的价格单位。
例如：1.4 美分／点、汇率 7，等于人民币 98 元／千点。
示例：60,000 点、买分 CPP 1.4、税费 50 美元、现金价 1,200 美元：
兑换总成本 890 美元，成本倍率约 1.35，节省 310 美元（25.83%）。
兑换 CPP 约 1.917，点数价值倍率约 1.37。
分母为零时，对应指标显示「不适用」；允许负节省和负兑换 CPP。
未计入现金票赚取的里程、退改差异、刷卡手续费和额外权益。

四、汇率
来源：https://frankfurter.dev/
接口：https://api.frankfurter.dev/v2/rate/USD/CNY
使用日度参考汇率，不是银行实际成交价；显示来源数据日期和本地获取时间。
自动模式在打开页面时检查缓存，超过 6 小时则尝试更新；也可点击更新按钮。
直接编辑汇率会进入手动模式，重开页面后仍保留。
点击「恢复自动汇率」才会重新使用联网结果。更新失败保留当前值，不阻止计算。
来源数据日期可能与设备当地日期不同。

五、现金票价与查询辅助
本版已接入 SerpApi；自动报价需本地 Python 服务和 API key，详见 SerpApi配置说明.txt。
单文件仍支持离线手动计算；自动票价需逐程选择、核对整程总价后应用。
手动查询辅助会将城市、日期、行程、舱位、人数和航班号组合为 Google 搜索条件。
仅点击搜索时才会把这些条件发给 Google；请在航司或订票网站核对匹配结果及含税总价。
支持选择同航班现金价，或实际愿意购买的替代机票价格作为比较基准。

六、保存与隐私
输入、手动汇率、常用价格（最多 8 个）和查询条件只保存在当前浏览器 localStorage。
没有账号，不跨设备同步。不同浏览器、file 与 localhost、不同端口分别保存。
浏览器禁止本地存储时会明确提示，仍可计算。清理浏览器数据会删除保存内容。
清空本次输入会保留汇率和常用买分价格。常用价格可单独删除。
旧版三种单项换算保留在 legacy.html，其原有本地数据不受影响；旧版不自动换汇。
