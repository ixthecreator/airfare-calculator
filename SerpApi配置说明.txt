SerpApi 自动票价 · 配置与使用

1. 获取密钥
在 https://serpapi.com/ 注册账号，在 https://serpapi.com/manage-api-key 查看 API key。
无需把密钥发到聊天，也不要写进 HTML。免费额度和价格以账号页面为准。

2. 最简单的启动方式（需 Python 3）
macOS：双击“启动自动票价-mac.command”。
Windows：双击“启动自动票价-windows.bat”。
终端会隐藏输入，让你粘贴 API key 并回车；密钥仅存在本次服务进程内，关闭后不会保存。
页面自动打开 http://localhost:8765/。

也可以在本目录终端运行：
macOS：python3 server.py --ask-key --open
Windows：py -3 server.py --ask-key --open
如已在进程环境配置 SERPAPI_API_KEY，直接运行 server.py 即可，不需要 --ask-key。

3. 手机访问
同一 Wi-Fi 下启动时加 --lan：
macOS：python3 server.py --ask-key --lan --open
Windows：py -3 server.py --ask-key --lan --open
用手机打开终端显示的局域网地址，电脑需保持运行。同一局域网能访问此服务的设备可以使用你的查询额度；不要将端口转发到公网。
端口占用时加 --port 8766。
若 macOS 的 Python 缺少 HTTPS 证书，可执行 python3 -m pip install certifi；服务会自动补充该可信根证书库，并始终验证 HTTPS 证书。

4. 使用
展开“查询现金票价”，填写三字母机场代码（JFK/PVG 等）、日期、乘客分类、舱位。
“同航班现金价”需要每程航班号。转机顺序用逗号分隔，例如 NH110,UA123。
“愿意买的替代机票”允许不填航班号，从返回结果选择；如果填了航班号，也会按该条件筛选。
往返需填写返程日期和返程航班号。
多城市的首程用上方字段填写，其他行程每行：出发机场 到达机场 日期 航班号。
例：PVG HND 2026-12-10 JL086（仅格式示例，不表示该日期班期已核实）。
自动查询合计最多9位乘客，怀抱婴儿数不超过成人数。日期按每个机场当地起飞日期填写。
自动报价固定使用美国销售市场，币种跟随现金票价USD/CNY。

已指定直飞航班号的单程或往返，会直接请求该完整行程的报价；其他查询需逐程选择航班。搜索阶段金额只是参考，不直接填入计算器。
完成所有行程后获取完整行程售票选项。系统核对每程航班号、机场、日期及舱位，跳过分开出票和已注明电话附加费的选项。
请点击Google Flights来源链接，确认价格覆盖全部乘客与完整行程、含税，且接受行李/退改条件；勾选确认后“使用此报价”。
系统使用来源数值，不再次乘以人数；若来源是每人价或额外费用未包含，请手动填写整组总价。
售票方可能使用共享航班号，页面会展示来源提供的营销航班号。最终支付金额以售票方为准。

5. 额度、缓存及限制
只有点击查询或继续选程才调用API；修改miles、税费或买分价不会查询。
指定直飞航班的单程/往返通常只需一次请求；其他完整行程可能需要多次请求（逐程搜索＋最终售票选项）。
本地同参数缓存5分钟；SerpApi自身可能缓存1小时，页面显示来源处理时间、本地获取时间与本地缓存标记。没有保证秒级实时。
本地设定每小时最多50次外部请求、不同查询至少间隔2秒。查询选择15分钟过期。
无匹配、错误、超时或额度不足时保留当前现金价；改动条件或手动价格会废弃旧结果。
混合舱位、来源缺失完整航程、来源缺失续程/核价token等情况可能无法导入，继续使用手动输入。
已使用真实API验证 JL5、JFK→HND、2026-12-20、1位成人、头等舱单程的报价链路；其他航线覆盖率与真实多人报价口径仍需逐次核对。

6. 离线版本
双击“机票兑换成本计算器.html”仍可离线计算，但不能自动查价。
自动票价应使用 http://localhost:8765/ 或局域网地址，不是在file://单文件页面中填入key。
